# Tor Production Addressables Automation

This editor-only package provides explicit configuration plus deterministic Addressables group and scene synchronization. Installation and configuration reads are inert. Start at **Project Settings > Tor Production > Addressables Automation**, select an editor-only `AddressablesAutomationConfig`, and use the relevant no-change Analyze action before any Apply.

See [Group synchronization](GROUP_SYNCHRONIZATION.md) and [Scene synchronization](SCENE_SYNCHRONIZATION.md) for rule semantics, conflicts, recovery, public API, and CLI usage. See [Safety notice](SAFETY.md) for workflows that remain disabled in this preview.
