# Tor Production Addressables Automation

This editor-only package provides explicit configuration, deterministic Addressables group and scene synchronization, and fail-closed duplicate-dependency analysis. Installation and configuration reads are inert. Start at **Project Settings > Tor Production > Addressables Automation**, select an editor-only `AddressablesAutomationConfig`, and use the relevant no-change Analyze action before any Apply or Fix.

See [Group synchronization](GROUP_SYNCHRONIZATION.md), [Scene synchronization](SCENE_SYNCHRONIZATION.md), and [Dependency analysis](DEPENDENCY_ANALYSIS.md) for rule semantics, conflicts, recovery, and compatibility. See [Safety notice](SAFETY.md) for workflows that remain disabled in this preview.
