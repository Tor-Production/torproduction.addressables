# Tor Production Addressables Automation

This editor-only package provides explicit configuration, deterministic Addressables group and scene synchronization, fail-closed duplicate-dependency analysis, and explicit recoverable content builds. Installation and configuration reads are inert. Start at **Project Settings > Tor Production > Addressables Automation**, select an editor-only `AddressablesAutomationConfig`, and use the relevant no-change Analyze action before any Apply or Fix.
